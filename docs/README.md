# Formação Java Backend - Thiago

Este repositório registra minha formação prática em Java Backend, do fundamento ao nível avançado, com foco em desenvolvimento profissional, arquitetura, boas práticas, testes, banco de dados, Spring Boot, segurança, cloud, mensageria e preparação para mercado.

## Objetivo

Meu objetivo é evoluir até o nível de Engenheiro Java Backend / Arquiteto Java, construindo uma base sólida em programação, backend, arquitetura e entrega de software profissional.

## Ambiente utilizado

- Java 21 LTS
- Eclipse Temurin JDK 21

- Windows
