## Por que Java?

Java é a linguagem mais utilizada em sistemas corporativos do mundo.

Bancos, fintechs, sistemas de saúde, e-commerce, logística, seguradoras — a grande maioria dos sistemas críticos que movimentam o Brasil e o mundo roda sobre Java ou uma linguagem derivada da JVM.

Aprender Java do jeito certo abre portas em empresas que pagam bem, que têm times sérios e que precisam de desenvolvedores que entendem o que estão fazendo.

## A diferença entre quem termina e quem evolui de verdade

Existem dois tipos de pessoa que começam um curso como este.

**Tipo 1 — Colecionador de aulas:**

Avança rápido sem praticar. Lê o código mas não digita. Pede para IA resolver. Acha que terminar o vídeo é aprender. Seis meses depois, não sabe explicar nem o que é um `ArrayList`.

**Tipo 2 — Desenvolvedor em construção:**

Pratica cada aula. Digita o código. Quebra. Corrige. Registra o erro no diário de bordo. Commita. Explica com as próprias palavras. Seis meses depois, consegue fazer um CRUD completo com Spring Boot e sabe por que cada linha existe.

Esta formação foi projetada para o **Tipo 2**.

Se você vier com a postura certa, o resultado é garantido pelo próprio processo.

## Como estudar esta formação

### Regra 1 — Praticar é obrigatório

Leitura sem prática não é aprendizado. É entretenimento.

Para cada aula com código, você deve:

1. Ler o conteúdo com atenção
2. Digitar o código (não copiar)
3. Executar e observar o resultado
4. Quebrar de propósito para entender o erro
5. Corrigir e entender por que funcionou

### Regra 2 — Registrar é obrigatório

Cada aula deve ter uma entrada no seu diário de bordo.

O modelo mínimo:

```markdown
## Aula XXX — Título

### O que aprendi
### O que pratiquei
### Erros que encontrei e como corrigi
### Próximo passo
```

Quem registra consolida. Quem não registra esquece.

### Regra 3 — Commitar é obrigatório

Cada prática relevante deve ir para o seu repositório Git.

Isso cria histórico, prova evolução e treina o hábito profissional que toda empresa cobra.

### Regra 4 — Não avance com dúvida aberta

Se não entendeu, revise. Pergunte. Pesquise. Use a IA para esclarecer — mas nunca para resolver no seu lugar.

A base fraca compromete tudo que vem depois.

## Como usar IA com inteligência

IA é uma ferramenta poderosa quando usada com método.

**Uso correto:**
- Pedir explicação de um conceito com suas próprias palavras
- Pedir analogias para entender melhor
- Pedir revisão do seu código depois de escrever
- Pedir casos de teste para validar sua solução
- Pedir diagnóstico de um erro que você não consegue resolver

**Uso errado:**
- Pedir o código pronto antes de tentar
- Colar sem ler e sem entender
- Aceitar qualquer sugestão sem validar
- Usar IA para substituir o raciocínio que você precisa treinar

A regra central: **IA pode ajudar você a pensar. Ela não deve pensar no seu lugar.**

## Os níveis de evolução desta trilha

A formação respeita os níveis reais do mercado:

**Júnior**
Escreve código que funciona. Sabe usar as ferramentas básicas. Precisa de supervisão para decisões de design.

**Pleno**
Entrega funcionalidades completas. Sabe testar. Entende o impacto do que faz. Trabalha com autonomia nas tarefas do dia a dia.

**Sênior**
Resolve problemas complexos. Cuida da qualidade da equipe. Pensa em manutenção, evolução e impacto técnico de longo prazo.

**Engenheiro Backend**
Domina a stack completa. Projeta soluções. Decide arquitetura com critério. Sabe comunicar decisão técnica.

**Arquiteto de Sistemas**
Entende o negócio além do código. Desenha sistemas distribuídos. Equilibra trade-offs de escalabilidade, resiliência e custo.

Esta trilha foi construída para você chegar ao nível de Engenheiro e ter o vocabulário e a base para evoluir ao nível de Arquiteto.

## Antes de começar — configure o ambiente

A primeira tarefa prática desta formação é preparar o ambiente de desenvolvimento.

Você vai precisar de:

- **JDK 21 LTS** — a versão atual com suporte de longo prazo
- **IntelliJ IDEA Community** — a melhor IDE Java gratuita do mercado
- **Git** — controle de versão obrigatório
- **Maven** — gerenciador de builds para projetos Java
- **Docker Desktop** — para rodar bancos e serviços em containers
- **PostgreSQL + DBeaver** — banco relacional e client visual
- **Postman ou Insomnia** — para testar APIs

Tudo isso é coberto em detalhes no **Módulo 0**, que começa na próxima aula.

Não pule o M0. Ambiente ruim vai travar você no M4, no M9 e no M11.
