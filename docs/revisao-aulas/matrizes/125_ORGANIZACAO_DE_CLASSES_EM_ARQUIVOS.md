# Matriz de cobertura — Aula 125

## Organização de classes em arquivos

| Conteúdo da aula oficial | Experiência guiada reconstruída |
|---|---|
| Relação entre classe `public` e nome do arquivo | Regra visual, código compilável e dois erros reais provocados com `javac` |
| Uma classe pública de topo por arquivo | Comparação entre duas classes públicas, classe auxiliar package-private e arquivo correto |
| Exemplo didático em arquivo único | Laboratório de crescimento com Pedido, Cliente, Dinheiro e Status no mesmo `.java` |
| Quando separar classes | Decisor baseado em importância, reuso, regra própria, testes e evolução independente |
| Pedido em arquivos separados | Árvore navegável com App, entidade, cliente, objeto de valor e enum |
| Compilar e executar múltiplos arquivos | Terminal guiado com `javac *.java` e execução da classe App |
| Visibilidade entre arquivos | Métodos públicos contextualizados como contrato entre classes separadas |
| Organização de uma ordem de serviço | Segunda árvore com entidade, código, período, status e turno |
| Recursos do IntelliJ | Mock visual de Project, New Java Class, Rename, Move, Find Usages e Navigate to Class |
| Nomes, duplicidade e arquivos auxiliares | Critérios explícitos e clínica com oito falhas recorrentes |
| Organização física versus arquitetura | Alerta didático: mover arquivos não corrige responsabilidades mal modeladas |
| Atividade, depuração e desafio | Navegação em seis saltos e Contrato final com oito arquivos e oito testes |

## Garantias

- Nenhum conceito da fonte oficial foi descartado; repetições foram consolidadas em decisões e práticas observáveis.
- A aula contém 21 fontes Java válidas, duas fontes deliberadamente inválidas, três árvores de arquivos e saída esperada no terminal.
- A conclusão da aula depende das 11 etapas; cada etapa pode ser concluída e desmarcada.
- O roteiro mantém foco no celular e a navegação da aula permanece responsiva e fixa no padrão global.
