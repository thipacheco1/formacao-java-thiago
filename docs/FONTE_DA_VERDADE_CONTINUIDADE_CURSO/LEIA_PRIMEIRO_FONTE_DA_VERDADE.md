# Leia primeiro - Fonte da verdade da continuidade

Esta pasta reune os arquivos essenciais para continuar a formacao Java Backend sem perder sequencia, nomes, profundidade ou objetivo pedagogico.

Use esta pasta quando for abrir um novo chat para continuar gerando as aulas.

## Ordem de leitura obrigatoria

O novo chat deve ler nesta ordem:

```text
1. LEIA_PRIMEIRO_FONTE_DA_VERDADE.md
2. PROMPT_MESTRE_CONTINUAR_CURSO_JAVA.md
3. ROTEIRO_OPERACIONAL_RECONSTRUIDO_COMPLETO.md
4. GRADE_OPERACIONAL_RECONSTRUIDA_COMPLETA.csv
5. ANALISE_GRADES_E_ROTEIRO_CONTINUIDADE_POS_259.md
6. 259_M11_15_DOCKER_JAVA_BACKEND_CONTAINERS_IMAGENS_DOCKERFILE_COMPOSE_OFICIAL.md
```

## O que cada arquivo faz

```text
PROMPT_MESTRE_CONTINUAR_CURSO_JAVA.md
Prompt pronto para colar no novo chat. Define o ponto exato de retomada, regras editoriais, proxima aula e limites.

ROTEIRO_OPERACIONAL_RECONSTRUIDO_COMPLETO.md
Explica a estrategia completa: o que ja foi feito, o que falta, como usar a grade e como evitar que o curso se perca.

GRADE_OPERACIONAL_RECONSTRUIDA_COMPLETA.csv
Grade operacional linha a linha de 000 a 720. Contem status, modulo, titulo, arquivo, fonte de decisao e regra de continuidade.

ANALISE_GRADES_E_ROTEIRO_CONTINUIDADE_POS_259.md
Analise das grades antigas comparadas com a sequencia real das aulas geradas.

259_M11_15_DOCKER_JAVA_BACKEND_CONTAINERS_IMAGENS_DOCKERFILE_COMPOSE_OFICIAL.md
Ultima aula real gerada. Deve ser lida porque ela faz a ponte direta para a aula 260.

REVISAO_EDITORIAL_V2/PADRAO_EDITORIAL_AULA_V2.md
Novo padrao editorial para as proximas aulas e para revisoes futuras: separa AULA de MATERIAL COMPLEMENTAR sem remover conteudo tecnico importante.

REVISAO_EDITORIAL_V2/M0_PLANO_DE_REVISAO_EDITORIAL.md
Plano inicial de curadoria do Modulo 0, com decisao aula a aula sobre o que fica na aula principal e o que vira complemento.
```

## Regras que nao podem ser quebradas

- Nao reescrever aulas antigas.
- Nao renomear arquivos antigos.
- Nao mudar numeracao.
- Nao trocar o modulo atual.
- Nao pular para Spring Boot ainda.
- Nao iniciar SQL antes de fechar o M11.
- Gerar uma aula por vez.
- Ler a aula anterior antes de gerar a proxima.
- Usar a CSV reconstruida como roteiro operacional das aulas futuras.
- Usar `docs/aulas` como fonte da verdade das aulas ja geradas.
