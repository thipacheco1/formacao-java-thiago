ATALHOS INTELLIJ - FORMAÇÃO JAVA

1. Criar método main
Digitar: main + Tab
ou: psvm + Tab

Resultado:
public static void main(String[] args) {

}

2. Criar System.out.println
Digitar: sout + Tab

Resultado:
System.out.println();

3. Executar programa
Shift + F10

4. Duplicar linha
Ctrl + D

5. Apagar linha
Ctrl + Y

6. Formatar código
Ctrl + Alt + L

7. Comentar ou descomentar linha
Ctrl + /
Exemplo:
Transforma uma linha em comentário usando //

8. Criar novo arquivo ou classe
Alt + Insert
Uso:
Dentro de uma pasta, permite criar novo arquivo, classe Java, pacote, entre outros.

9. Renomear variável, classe ou arquivo com segurança
Shift + F6

Uso:
Seleciona uma variável, classe ou arquivo e renomeia em todos os pontos necessários.

10. Auto completar sugestões
Ctrl + Espaço

Uso:
Mostra sugestões de código, variáveis, métodos e classes disponíveis.

11. Ir para o final da linha
End

12. Ir para o começo da linha
Home

13. Selecionar linha atual
Shift + End ou Shift + Home

Uso:
Ajuda a editar código mais rápido no IntelliJ.

14. Exibir ações rápidas / sugestões de correção
Alt + Enter

Uso:
Quando o IntelliJ sublinha algo ou mostra sugestão, Alt + Enter abre opções de correção, importação, ajuste ou melhoria.

15. Rodar novamente a última execução
Ctrl + F5

Uso:
Executa novamente a última configuração rodada no IntelliJ.

16. Recuar/indentar código automaticamente
Tab

17. Voltar indentação
Shift + Tab

Uso:
Ajuda a organizar blocos de código dentro de if, else, métodos e classes.
