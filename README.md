## 🌐 Acesse a Plataforma Interativa

> **Plataforma Aberta e Gratuita:** [formacao-java.vercel.app](https://formacao-java.vercel.app)

A **Formação Java Completa** é uma plataforma educacional interativa projetada para formar Engenheiros de Software Backend. O currículo engloba **721 aulas práticas guiadas**, divididas em **5 fases** e **21 módulos evolutivos** — da compilação e modelo de memória da JVM até Arquitetura de Sistemas Distribuidos, DDD, Kafka e Kubernetes.

---

## 🗺️ Estrutura Curricular (5 Fases / 21 Módulos)

### 🟦 Fase 1: Base Java e Domínio (`P0`, `M0` - `M4` | Aulas 000-145)
- **P0 & M0:** Método de Estudo, Rotina e Configuração Profissional (JDK 21 LTS, IntelliJ, PowerShell, Git, Docker).
- **M1:** Fundamentos Absolutos (Sintaxe, operadores, controle de fluxo, arrays, matrizes, métodos).
- **M2:** Java Core Profundo (JVM, modelo de memória, registros `records`, I/O, exceptions).
- **M3 & M4:** Quebra de responsabilidades, coesão, refatoração, Orientação a Objetos e modelagem de domínio.

### 🟪 Fase 2: Java Moderno e Design (`M5` - `M10` | Aulas 146-244)
- **M5:** Collections Framework (`List`, `Set`, `Map`, filas, comparadores).
- **M6:** Generics e `Optional` (PECS, wildcards, type erasure).
- **M7:** Programação Funcional (Lambdas, `Functional Interfaces`, Streams API, Collectors).
- **M8:** Exceptions, I/O, CSV robusto, `java.time` e UUID.
- **M9 & M10:** Princípios SOLID e Design Patterns GoF (Strategy, Factory, Adapter, Observer) aplicados ao backend.

### 🟩 Fase 3: Ferramentas, Banco e Spring (`M11` - `M14` | Aulas 245-410)
- **M11:** Ferramentas Backend (Maven, Gradle, JUnit, Docker, CI/CD).
- **M12:** SQL e PostgreSQL (Modelagem relacional, consultas, índices, transações).
- **M13:** Persistência Java (JDBC puro, JPA, Hibernate, Spring Data, tuning de consultas).
- **M14:** Spring Boot e REST APIs (DTOs, Bean Validation, tratamento de erros, OpenAPI/Swagger).

### 🟧 Fase 4: Segurança, Integrações e Produção (`M15` - `M18` | Aulas 411-610)
- **M15:** Segurança (Spring Security, JWT, OAuth2, mitigação OWASP).
- **M16:** Integrações e Mensageria (APIs externas, resiliência, RabbitMQ, Kafka, SAGA, Outbox Pattern).
- **M17:** DevOps, CI/CD, Kubernetes e Cloud (Containers, pipelines, K8s, deploy).
- **M18:** Observabilidade e Performance (Logs estruturados, métricas, distributed tracing, tuning de JVM, concorrência).

### 🟥 Fase 5: Arquitetura e Defesa Técnica (`M19` - `M20` | Aulas 611-720)
- **M19:** Arquitetura, DDD e Sistemas Distribuidos (Aggregates, Value Objects, Domain Events, Event Sourcing, CQRS).
- **M20:** Projeto Final, Portfólio, Entrevistas e Defesa em Banca Técnica.

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java 21 LTS
- **Build & Dependências:** Maven / Gradle
- **Banco de Dados:** PostgreSQL & H2
- **Frameworks:** Spring Boot 3x, Spring Data JPA, Spring Security
- **DevOps & Infra:** Docker, Kubernetes, GitHub Actions
- **Mensageria:** Apache Kafka & RabbitMQ
- **IDE:** IntelliJ IDEA
